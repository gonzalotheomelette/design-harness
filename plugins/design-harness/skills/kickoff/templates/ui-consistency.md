# Sibling-surface consistency rules

The rules that make sibling surfaces match, for the `ui-review` agent. Each row is a decision the designer already
made, so a change that breaks it is a slip, not a matter of taste. Add a row with `/design-harness:learn` whenever
the designer corrects something a sibling or a rule would have caught, in the same commit as the fix.
